For Bicet, here is what we intended on doing 3 years ago, Rest in Power.

Roms such as Pure Nexus, Dirty Unicorns, Resurrection Remix, and Screw'd, the many derivatives of AOSPA, focused on actual stability and improvements over stock android.

We will continue that thought process and add everything that is worth adding, without breaking functionality and adding useless features bc another rom has it. 

Use as much aosp as the good Google gives us.
This rom will only support newer generation pixels. 

sync it:

git lfs install && repo init -u https://github.com/Pure-Pixel/manifest -b 15 --git-lfs

source build/envsetup.sh && lunch komodo-ap3a-userdebug && m && m updatepackage'

I recommend setting the sync and build commands as aliases so you dont have to type so much..
